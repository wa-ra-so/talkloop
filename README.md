# IENA面接ドリル

米国J-1研修プログラムのスポンサー「IENA」の担当者面接に向けた、英語のリスニング・スピーキング練習ツールです。

公開URL: https://wa-ra-so.github.io/talkloop/

## 3つの段階

| 段階 | やること | 次へ進む目安 |
|---|---|---|
| STEP 1 練習 | 英文を見ながらお手本を聞き、まねして3回音読する | 全カードの音読が完了 |
| STEP 2 習得 | 英文を見ずに質問を聞き、ヒントの要点だけで答えてから、お手本で確認する | 8割以上が「言えた」 |
| STEP 3 模擬面接 | 本番の速度で質問が続けて流れる(英文・ヒントなし)。最後にまとめて自己評価し、「もう一度」の問題は習得に戻る | — |

教材は2種類です。

- **お助けフレーズ(8個)**: 聞き取れない・意味がわからないときに使う英語。面接官の発言を聞いて、どのフレーズで返すかを練習します。
- **面接Q&A(24問)**: 自己紹介、経歴、研修の理由、受入先、帰国後、生活の6カテゴリ。

## 仕様

- 1ファイル構成(`index.html` にスタイルとスクリプトをすべて記述)。ビルドは Vite。
- 読み上げはブラウザの音声合成(Web Speech API)。速度は「ゆっくり/ふつう/本番」の3段階。
- 進み具合は `localStorage` に保存(端末内のみ)。
- 録音・発音判定はありません。評価は自己評価です。

## 内容の更新

質問と回答は `index.html` の `PHRASES` と `QA` の配列にあります。研修計画(DS-7002)の質問は未完成のため、`todo: true` にして模擬面接から外しています。内容が決まったら、その行の `a` と `aj` を書き換え、`todo: true` を消してください。

## ローカルで動かす

```bash
npm install
npm run dev
```

`main` ブランチに push すると、GitHub Actions (`.github/workflows/deploy.yml`) がビルドして GitHub Pages に公開します。

以前の会話文法アプリ(Talkloop)は、git の履歴 `114f92e` から復元できます。
