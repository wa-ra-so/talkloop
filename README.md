# IENA面接ドリル

米国J-1研修プログラムのスポンサー「IENA」の担当者面接に向けた、英語のリスニング・スピーキング練習ツールです。

公開URL: https://wa-ra-so.github.io/talkloop/

## 3つの段階

| 段階 | やること | 次へ進む目安 |
|---|---|---|
| STEP 1 練習 | 英文を見ながらお手本を聞き、まねして3回音読する | 全カードの音読が完了 |
| STEP 2 習得 | 英文を見ずに質問を聞き、ヒントの要点だけで答えてから、お手本で確認する | 8割以上が「言えた」 |
| STEP 3 模擬面接 | 本番の速度で質問が続けて流れる(英文・ヒントなし)。「対話モード」と「手動モード」がある。最後にまとめて自己評価し、「もう一度」の問題は習得に戻る | — |

教材は3種類です。

- **お助けフレーズ(8個)**: 聞き取れない・意味がわからないときに使う英語。面接官の発言を聞いて、どのフレーズで返すかを練習します。
- **面接Q&A(24問)**: 自己紹介、経歴、研修の理由、受入先、帰国後、生活の6カテゴリ。
- **単語・型(40個)**: 回答に何度も出てくる**重要ワード(24個)**と、答えの骨組みになる**頻出フレーズ(16個)**。練習では単語と例文を音読し、習得では日本語から英語を言ってから例文ごと言えるか確かめます。日本人が間違えやすい点(「ホール」は hall ではない、など)はヒントとして表示します。

## 対話モード(模擬面接)

面接官が質問を読み上げ、声で答えると自動で次の質問に進みます。

- 答え終わって決めた秒数(3・5・8秒から選択、初期値5秒)黙ると回答終了とみなし、「Thank you.」などの相づちのあと次の質問を読み上げる
- 回答中に英語で聞き返すと面接官が反応する:「Could you speak more slowly?」→ゆっくり繰り返す、「Could you say that again?」→繰り返す、「Let me think for a moment.」→待つ、「Do you mean 〜?」→答える
- 回答は文字で記録し、最後に語数・秒数・聞き直し回数・お手本の重要語をいくつ使えたかを表示する
- 音声認識はブラウザの Web Speech API(英語)。AndroidやPCのChrome、iPhoneのSafariで動作。Chromeでは音声がGoogleのサーバーで文字にされる
- 認識結果は発音の目安で、採点ではない

## 仕様

- 1ファイル構成(`index.html` にスタイルとスクリプトをすべて記述)。ビルドは Vite。
- 読み上げはブラウザの音声合成(Web Speech API)。速度は「ゆっくり/ふつう/本番」の3段階。
- 進み具合は `localStorage` に保存(端末内のみ)。
- 録音・発音判定はありません。評価は自己評価です(対話モードの文字起こしは目安)。
