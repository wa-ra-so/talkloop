# Talkloop 🗨️

**2ヶ月で日常会話の文法を身につける、フレーズ優先の学習ツール。**

「文法用語を覚える」のではなく、まず知っているフレーズを土台にして、新しい形を予想してから答え合わせをする — という進め方（predict → check）で、生活の中で使える会話文法を練習します。FSRS（間隔反復アルゴリズム）で、忘れかけたタイミングで自動的に復習が出てきます。

## 使い方

1. トップ画面で「レビューを始める」を押す
2. 日本語のお題を見て、まず自分なりに英語を入力してみる（自己採点なので正確さは気にしなくてOK）
3. 「こたえを見る」でお手本と簡単な解説を確認
4. 「もう一度／難しい／できた／簡単」の4段階で自己評価 → 次にいつ復習するかが自動で決まる
5. 生活の中で「これ英語で言いたかった」と思ったフレーズは「＋自分のフレーズを追加」でいつでも追加できる

## コンテンツ構成（2ヶ月分）

- **基本フレーズ（30個）**: 挨拶・買い物・道案内・誘い方・意見・トラブル対応など、生活のあらゆる場面で使う核となるフレーズ
- **Week 1〜7（文法パターン、各10〜12枚）**: 現在完了vs過去形 → 冠詞・可算/不可算 → 前置詞 → 助動詞（誘い・断り）→ 関係詞・分詞 → 仮定法 → 受動態・使役・話法
- **Week 8（総復習）**: 英語日記を書くつもりで、これまでの文法を混ぜて使う

内容は `src/data/cards.ts` にすべて定義されています。新しいカードを追加したいときは、同じファイルに `phrase(...)` または `grammar(...)` ヘルパーで追記するだけです。

```ts
grammar(2, 'トピック名', '日本語のお題', 'This is the model answer.', {
  hint_ja: '知っている形のヒント（任意）',
  cloze: 'This ___ the model answer.', // 空所ドリル（任意）
  note_ja: '短い文法解説（任意）',
});
```

## 技術構成

- Vite + TypeScript（フレームワークなしの軽量構成）
- [`ts-fsrs`](https://github.com/open-spaced-repetition/ts-fsrs) — FSRSアルゴリズムによる間隔反復スケジューリング
- データ保存は `localStorage`（端末内のみ。バックエンドなし、サーバーなし）
- `src/lib/storage.ts` で `localStorage` が使えない環境でも落ちないようフォールバックを用意

## ローカルで動かす

```bash
npm install
npm run dev
```

## デプロイ

`main` ブランチに push すると GitHub Actions (`.github/workflows/deploy.yml`) が自動でビルドし、GitHub Pages に公開します。リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください。

## 設計の背景

学習方法は [PIVOT TALK × Kazu Languages](https://youtu.be/Q5GDR7P39GE) で紹介されている「コアフレーズを先に身につけ、そこから新しい文法を予想してから確認する」というアプローチを参考にしています。カード設計・間隔反復の考え方は、複数のAIモデル（Claude Opus 5 / GPT-5.6 Sol / Gemini 3.1 Pro）による独立調査の統合レポートをベースにしています。
